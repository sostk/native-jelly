# v0.10.0 — Dolby Vision Profile 7, scrub previews and subtitles in more scripts

Dual-layer Dolby Vision films that used to fall back to a converted, washed-out picture can now play in Dolby Vision. This release also adds scrub preview thumbnails, Previous/Next episode buttons and subtitles in scripts such as Hebrew, Arabic and Thai, and fixes several playback, quality-selection and exit problems reported by users.

## What's new

- **Dolby Vision Profile 7 plays in Dolby Vision.** Single-track Profile 7 HEVC files, common in Blu-ray remuxes, are converted on the television to a form it can display, while Jellyfin sends the video unchanged. A set without Dolby Vision should play them in HDR10; that was checked only by making a Dolby Vision set report it had none. Previously the server re-encoded them, which could produce a washed-out SDR picture.
- **AV1 Dolby Vision.** AV1 files carrying Dolby Vision Profile 10 are offered as Dolby Vision on televisions that advertise both an AV1 decoder and Dolby Vision.
- **Scrub preview thumbnails.** When your Jellyfin server has generated trickplay images for a video, a thumbnail of the destination appears above the progress bar while you seek. Videos without them seek exactly as before.
- **Previous/Next episode buttons in the player**, beside Subtitles and Audio. Previous restarts the current episode after its first five seconds. Turn them off in **Settings → Video & playback → Previous/Next buttons**.
- **Faster seeking controls.** The remote's fast-forward and rewind keys now jump by the skip interval with a single press. **Settings → Video & playback → Instant D-pad seeking** (off by default) makes Left and Right jump straight away while the controls are hidden.
- **Subtitles in 22 more scripts.** Hebrew, Arabic, Thai, Devanagari and other scripts the app's font lacked used to appear as empty boxes; the app now bundles matching Noto Sans faces for them. Thanks to [dorko87](https://github.com/dorko87) for the port.
- **Text subtitles share the styled-subtitle renderer.** SRT, WebVTT and MP4 text subtitles, embedded or as separate files, are drawn the same way as ASS subtitles, and older non-Unicode files (such as GBK, Big5 or Shift_JIS) are detected per track instead of appearing garbled.
- **Choose what BACK does on Home.** **Settings → Back on Home** can show LG Home (the previous behaviour), exit the app, or open another installed app, for example a custom launcher. Thanks to [Anarh2404](https://github.com/Anarh2404) for the request and for testing it.
- **New library items appear without restarting the app.** Every five minutes, and when you return to the app, it asks your server whether the library changed and refreshes Home and the library if it did. This has not yet been checked against a real addition or removal on a server.
- **Magic Remote edge scrolling.** Resting the pointer near the edge of a page or row scrolls it, and hovering over a card no longer moves the page. It has not yet been tried on a television here.

## Fixed

- **Some files showed only an error or a black screen when the television could not decode their audio.** They now play with the server converting the audio and sending the video unchanged. Thanks to [mattokar](https://github.com/mattokar) for the report and for confirming the fix.
- **HEVC files above the quality limit failed to play.** When Jellyfin re-encoded a high-bitrate HEVC file to H.264, the app expected HEVC and rejected the stream. Thanks to [Anarh2404](https://github.com/Anarh2404).
- **Auto quality underestimated fast networks**, so files the connection could carry were converted. The speed test now measures a longer transfer instead of a single short burst. Thanks to [Anarh2404](https://github.com/Anarh2404).
- **The app could crash while closing.** Shutdown now releases the graphics context before closing the window and no longer runs library clean-up that could crash during exit. Thanks to [Anarh2404](https://github.com/Anarh2404) for the report and fix.
- **Seeking in some Blu-ray remuxes stayed on Buffering.**
- **Pausing during a seek could reload the video** instead of holding the paused picture.
- **An interrupted connection stopped direct play.** Short interruptions are now retried, and a failed playback is reported to Jellyfin as stopped exactly once.
- **An episode left during its credits stayed unwatched.** Going to the next episode from the credits now marks the finished one as played.
- **A new video could wait for the previous one to finish stopping**, and a television that never finished stopping could freeze the app. Stopping now happens in the background. This has not yet been timed on a television.
- Returning from a cast member's page keeps the page's scroll position; focus stays in the episode list when a season finishes loading; the A–Z rail keeps working with the Unwatched and genre filters.

## Compatibility

- **Plays video, verified by watching it — 2021 LG sets.** One television, an LG C1 running webOS 6.5.3, on which the new Dolby Vision, AV1, seeking, subtitle and scrub-preview paths were watched from a Jellyfin 12 server using development builds of these changes. Not every fix above was re-checked on it; the technical audit lists which were.
- **Plays video, reported by someone else — 2021 LG sets.** [mattokar](https://github.com/mattokar) reported Profile 7 Dolby Vision and audio-converted playback working on an LG C1 (webOS 6.5.3) with a 0.10.0 nightly build on 1 November 2026 ([#24](https://github.com/sostk/native-jelly/issues/24), [#27](https://github.com/sostk/native-jelly/issues/27)).
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up.** The release run checks this binary's libraries and symbols against every firmware image webosbrew has from platform release 4.4.2 up, and fails if any of them would refuse to start it; webosbrew has no image of platform releases 4.0 to 4.4.1, so those are expected to start but were not checked; the matrix is in the [technical audit](https://github.com/sostk/native-jelly/blob/main/docs/release-audits/v0.10.0.md). That grades startup and says nothing about whether video plays.

If your set is in the last group, [tell us what happened](https://github.com/sostk/native-jelly/issues). It working is as useful a report as it failing.

## Known issues

- **Direct play of some large Dolby Vision Profile 8 files with Atmos stops after about 45 seconds** on an LG C3, reported against a 0.10.0 nightly ([#36](https://github.com/sostk/native-jelly/issues/36)). Not yet investigated; this release does not change it.
- **Jellyfin libraries of the "Mixed Movies and Shows" type do not appear** ([#35](https://github.com/sostk/native-jelly/issues/35)).
- **Playback can fail over HTTPS through a reverse proxy.** Carried from earlier releases; these changes do not address it.
- **Video re-encoding remains H.264**, even when the server is allowed to encode HEVC.

## Help test this release

**If you have a set from 2022 or later, or one running webOS 4 or 5, try a Dolby Vision or AV1 film and a seek.** The Dolby Vision Profile 7 and AV1 Dolby Vision paths have only been watched on one 2021 C1. [Open an issue](https://github.com/sostk/native-jelly/issues) with your TV model and firmware, and whether Jellyfin reported direct play or conversion. It working is as useful a report as it failing.

## Installing

Download **com.sostk.nativejelly_0.10.0_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.sostk.nativejelly_0.10.0_arm.ipk
```

[Installing and checking a download](https://github.com/sostk/native-jelly/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.10.0](https://github.com/sostk/native-jelly/blob/main/docs/release-audits/v0.10.0.md).
