Changes in this release that were **not** observed on a television, and are claimed in the note only with that stated:

- Stop off the BACK frame and no blocking on a previous Unload (`c610b17b`, `6777da76`): host tests only. The pre-change BACK frame was measured at 61–81 ms; the post-change frame was not measured.
- Magic Remote edge scrolling (`621602d3`): not run on this set.
- Library change polling (`2fcdf662`): one request measured at about 20 ms; no real addition or removal was observed, because the test account is not a server administrator.
- Parallel independent requests (`2ab3bd6d`): no before/after timing.
- Back from a cast page, focus in the episode strip, A–Z rail under filters, poster eviction order (`689b78b0`, `19bc96dd`, `f567e1e9`, `c7bd13fe`): host regressions; the eviction route was never reached on the set.
- Recovery for a surround Opus feed the decoder swallows, and for a video refused before its first picture (`52420ace`, `540427ed`): host and ARM tests only. Opus direct play itself stays withheld from Auto and Force routing.
- Contributor PRs #32, #33, #34 and #37: reviewed and host-tested here; their device evidence is the contributors' own, below.
- The dependency updates in `f33de87d`, `d13d2c2e` and `3f9344bc` (FFmpeg 9.0.2, the libass stack): ARM release build and `make check` only.

## Compatibility tiers, and what moved

- **Plays video, verified:** unchanged — the one 2021 LG C1 (platform 6.5.3). The verification is per change on development builds, as listed above, not a watch of the release package.
- **Plays video, reported:** new line for 2021 sets, from mattokar's C1 reports in #24 and #27. Nothing else is promoted: Anarh2404's reports concern branch builds of exit and bandwidth changes, and therolla's C3 report is a failure.
- **Starts:** regenerated by the release run below; no matrix is copied in by hand.

## Known issues at release, with provenance

- **Dolby Vision Profile 8 + Atmos direct play stops after about 45 s:** therolla's report in #36 (C3, platform 11.2.0, nightly). Not reproduced here; the C1 has not been tried with that file shape.
- **Mixed Movies and Shows libraries not listed:** watsonmaster's report in #35, which notes the same library filter is in v0.9.0 and `main`. Not changed in this range.
- **HTTPS through a reverse proxy:** carried from the maintainer's observations recorded in the v0.8.0 audit; not addressed or re-tested in this range.
- **H.264 re-encoding:** `docs/jellyfin-playback.md` records why the server's encoder setting is not read. The new pre-picture recovery (`540427ed`) asks for a 1080p H.264 encode.

## Deliberately not done

- No television check of the release package, and no full device suite on the integrated tree. Install the published `.ipk` on the C1 (cut-release step 6) before announcing it.
- Owed TV checks that remain open: BACK-frame timing with Unload off the main thread, and rapid play→back→play with a held Unload; a route that reaches poster eviction; Back from a cast page and the season-strip focus case; edge glide on Home, Detail, Library and Search; a real 5.1/7.1 Opus feed and a real refused video for the new recovery steps; BACK during a slow load; 96 kHz audio sources; library polling and parallel requests on the set; library polling against a real addition and removal on a server.
- Listening checks were deferred throughout this range: feed acceptance and captures do not establish audible audio.
- Opus direct play remains staged and withheld from Auto, Force and the Jellyfin DeviceProfile.
- HarfBuzz 15.1.0 (released 4 November) was not taken; the libass stack matches upstream PlxNative's shipped versions. sentry-native stays at 0.16.6, and the move to stable Rust without `-Z build-std` was not made.
- No `make build-bench` before/after table was recorded for the dependency commits.
- Documentation screenshots were not regenerated as part of preparing these documents.
- The Homebrew Channel listing still describes v0.9.0; update it alongside the published release.
- The action-required review of added lines in `rust-modules/src`, `rust-modules/platform/src`, `rust-modules/base/src`, `src` and `ci` found new `TcpListener::bind` calls only inside test modules, test-only private-file helpers, and no new FIFO, listener, credential sink or file outside the app's own directories. New network traffic goes only to the signed-in Jellyfin server: trickplay manifests and sheets, one library-change request every five minutes and on returning to the foreground, and a longer Auto speed probe (up to 600 ms of a bitrate-test payload). Telemetry gained one failure class, `release_timeout`, and no new fields. No action-required section is owed.

## Release configuration

| | |
|---|---|
| flavour | `com.sostk.nativejelly` (stable) — the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK `webos-d7ed7ee.6` (unchanged), Rust nightly pinned by date in the `RUST_NIGHTLY` repository variable (unchanged) |

Unusual for this build:

- **Bundled C libraries moved:** FFmpeg 9.0 → 9.0.2 (same library majors, so the ABI table in `ff.rs` is unchanged), FreeType 2.14.3 → 2.15.0 (its new `hvf` module disabled), FriBidi 1.0.17 → 1.0.18, HarfBuzz 14.5.0 → 15.0.0; libass stays 0.17.5. Each tarball's sha256 was checked against its release download and against upstream PlxNative's pin. The LGPL corresponding source attached by the release run is therefore `ffmpeg-9.0.2.tar.xz`.
- **New Rust crates linked:** `dolby_vision` 3.4.0 and its dependencies for the Profile 7 conversion, and `chardetng` with `encoding_rs` for legacy subtitle encodings; all are listed in `THIRD-PARTY-NOTICES.md` §2.4. Existing crates moved to their latest minor/patch releases (`f33de87d`).
- **New payload files:** 22 subset Noto Sans Bold subtitle faces and their manifest under `fonts/subs/` (OFL 1.1, attributed in `THIRD-PARTY-NOTICES.md`), and a modified `appfont-bold.ttf`.
- No new outbound host, no new file written outside the app's own directories.
